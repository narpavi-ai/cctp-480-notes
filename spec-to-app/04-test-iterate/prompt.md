Use this pattern in Lovable's chat when something's broken or confusing.
Describe it like a bug report, not a vague complaint:

---

On **[screen name]**, when I **[exact steps to reproduce]**, **[what
actually happens]**.

I expected **[what should happen instead]**.

Do not change **[anything else that's already working — be specific]**.

---

If the same issue survives two or three attempts at this, stop re-prompting
the same fix. Switch to Plan mode instead and ask:

> Explain what's likely causing this before changing any code.
